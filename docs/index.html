The Problem

What Breaks Every Morning in a Tier 2 Clinic

These aren't edge cases. This is every clinic, every day, in Hubli, Gadag, Shimoga, Davangere, and 400 more towns like them.

📋

Paper Registers Fall Apart

Patient OPD numbers are written in a register. Finding a patient who visited 3 months ago takes 10 minutes of flipping. No UHID, no history, no continuity of care.

💊

Pharmacy Expiry Losses

No FEFO system. Drugs expiring in the back while newer stock gets sold first. Schedule H/H1 registers maintained in pencil. Drug inspector audit = panic.

📵

Internet Goes Down Daily

Cloud-only software fails when BSNL cuts out for 2 hours. The clinic has to stop billing. Patients wait. Cloud software was designed for Mumbai, not Mandya.

💬

No Patient Follow-Up

Appointment reminders are phone calls. The receptionist calls 30 patients every morning. Half don't pick up. 10 no-shows cost the doctor ₹5,000 in missed revenue.

🏥

IPD on Whiteboards

Bed occupancy tracked on a whiteboard. Nursing notes handwritten. Discharge summaries typed in MS Word. No connection between OPD, IPD, and pharmacy.

🧾

Billing Chaos

GST invoices done on Tally separately. Cash discrepancy at end of day. Insurance pre-auth done on phone calls. Daily revenue report = one column in Excel.

Opening & Discovery

0–5 minutes
"Doctor sahab / Madam, namaste. Main Sunil hun, Bridgr Technologies se. Aap ke clinic mein roughly kitne patients per day dekhte hain? Aur abhi billing aur patient records ka kya system hai — paper hai ya koi software use karte hain?"
💡

Listen first, don't pitch yet. You need to know: (1) patient volume, (2) current system (paper/Tally/old software), (3) who does billing — doctor, receptionist, or both. This shapes which modules to push.

🎯

Golden signal: If they say "paper register" or "Excel," they're a red-hot lead. If they say "we use some old software," ask what's frustrating them — usually Internet, support, or lack of WhatsApp.

Pain Amplification

5–10 minutes
"Kabhi aisa hua hai ki patient pehle aaya tha aur uska purana prescription dhundna pad gaya? Aur kitna time laga?" [pause]

"Pharmacy mein expiry check manually karte hain? Schedule H register ek alag copy mein rakhte ho?" [pause]

"Patients ko appointment reminder kaun bhejta hai? Receptionist call karti hai? Ek din mein kitne no-show hote hain?" [pause]

"Internet kabhi band hota hai? Tab billing band ho jaati hai kya?"
⚡

Don't answer their pain — amplify it. "Aur us din jab net band tha, aapne 10 patients ko wait karaya tha, toh roughly kitna revenue tha jo bill nahi hua?" Make them feel the cost before you show the solution.

Live Demo — 5 Key Moments

10–25 minutes · Show these 5 things only
1️⃣

New Patient in 20 seconds. Type name, phone. UHID auto-generated. "Yeh UHID is patient ka permanent number hai — agle 20 saal baad bhi aayenge toh same number se pura history milega."

2️⃣

GST Invoice in 30 seconds. Show the bill generate, PDF download, WhatsApp share in one click. "Receptionist ke paas mobile hai na? Yeh share kar degi — patient ko bhi milega aur aapke paas bhi record."

3️⃣

Offline Mode demo. Turn off WiFi. Show that billing still works. "Net band hai — chalta rahega. Data local machine mein hai. Cloud par depend nahi hai."

4️⃣

WhatsApp Automation. Show the "Reminder set" toggle. "Kal ka appointment set kiya — 6 baje subah patient ko WhatsApp jayega automatically. Receptionist ko kuch nahi karna."

5️⃣

Pharmacy Expiry Alert. If they have a pharmacy, show the FEFO stock view and expiry alert. "Agle 30 din mein jo bhi expire hone wala hai — yahan list aati hai. Drug inspector audit mein no problem."

Pricing Reveal

25–30 minutes
"Ab price baat karte hain. Base system — reception, billing, aur OPD sab — ₹8,999 per month. Agar WhatsApp automation chahiye, wo ₹1,999 extra. Pharmacy module add karna hai toh aur ₹1,000. IPD hai toh ₹1,000 aur.

Aapko sirf woh modules ke liye pay karna hai jo aapko chahiye. Installation fee ek baar ₹4,999 hai — usme hum aate hain, sab set up karte hain, staff ko train karte hain, aur 30 din support bhi dete hain.

Aur agar saal bhar ke liye pay karein toh 2 mahine free milte hain."
💡

Anchor with the annual number last. Say monthly first (smaller number), then drop the annual savings ("₹25,000 bachate ho"). Clinics with predictable revenue love annual billing — you collect cash upfront.

🎯

For a clinic with 50 patients/day: 10 no-shows saved per month = ~₹5,000 in recovered revenue. "Software ka cost ek no-show se kum hai." That's your ROI in one line.

Handle Objections

30–40 minutes
💰
"Bahut expensive hai."
"Doctor sahab, aapke clinic mein ek patient ka average bill kitna hai? ₹300–₹500? Agar har mahine sirf 20 patients zyada aate hain kyunki humara WhatsApp reminder ne unhe yaad dilaya — toh software free hai. Actually profit mein hain."

Plus: "Agar Practo use karo toh ₹5,999 sirf basic ke liye — aur offline nahi karta. Hum zyada dete hain, kam mein."
🤔
"Pehle try karke dekhna hai."
"Bilkul. Hum 14-din free demo dete hain actual clinic data ke saath. Main aata hun, sab set up karta hun, 14 din baad aap decide karo. Installation fee bhi baad mein lenge — pehle dekho software suit karta hai ya nahi."
📡
"Internet nahi hai toh kaise chalega?"
"Yahi toh hamara sabse bada feature hai. Internet bilkul zaruri nahi. Software aapki machine par run karta hai — LAN cable se dono computers connected hain, net nahi chahiye. WhatsApp reminders tab jayenge jab thodi der ke liye bhi net aayega."
🔐
"Data safe rahega? Cloud par jayega kya?"
"Data aapka, aapke paas. Hamare server par kuch nahi jata. Patient data aapke computer mein hi rehta hai. Optional Google Drive backup set kar sakte hain — lekin wo bhi aapka choice hai. DPDP Act compliance ke liye bhi yahi safest approach hai."
🛠
"Baad mein koi problem aaye toh support milega?"
"Haan — WhatsApp helpline pe direct mujhse baat kar sakte ho. 4 ghante mein response guaranteed. Aur agar koi technical issue aaya toh hum remotely bhi fix kar sakte hain zyada tar cheez. Aap akela nahi hoge."

Close & Next Steps

40–45 minutes
"Doctor sahab, ek kaam karte hain. Main kal subah 10 baje aata hun — free installation karta hun, demo data se setup karta hun. Aap dekho, staff ko dikhao. 14 din mein agar suit kiya, tab payment karo.

Agar suit nahi kiya — no problem, koi charge nahi. Deal?"
📅

Always ask for a specific time, not "kab miloge?" A vague "call karta hun" dies. A specific "kal subah 10 baje" gets confirmed or rescheduled to a real slot.

📲

Before you leave, send them a WhatsApp message right there: "Hi Doctor [Name], yeh CureDesk ka brochure hai — [link]. Kal 10 baje milte hain." You're in their WhatsApp chat now. Follow-up is easy.

🏆

After closing: Ask "Aap jaante hain kisi aur doctor ko jo is area mein software dhundh rahe hain?" One referral per close = 50% CAC reduction. Offer 1 month free for every successful referral.

GitHub Pages Deployment

Push This Website to GitHub Pages in 5 Steps

This file lives at docs/index.html in your mmcopd repo. Enable GitHub Pages to serve it as your public site.

1

Commit this file to your repo

The file is already at mmcopd/docs/index.html. Stage and commit it.

cd /Users/sunil/caredesk/mmcopd && git add docs/index.html && git commit -m "feat: add business portal website"
2

Push to GitHub

Push your local commits to the remote repo.

git push origin main
3

Enable GitHub Pages

Go to your repo on GitHub → Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /docs → Save.

4

Wait ~60 seconds, then visit your site

Your site will be live at:

https://mulgundsunil1918.github.io/mmcopd/
5

(Optional) Add a custom domain

In Pages settings, add a custom domain like hms.bridgr.in. GitHub provides free HTTPS via Let's Encrypt. Add a CNAME DNS record at your domain registrar pointing to mulgundsunil1918.github.io.
