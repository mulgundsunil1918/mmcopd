Multi-Station Setup & Recovery

CureDesk HMS · reception, doctor cabins & pharmacy sharing one clinic database over your own network — cable or Wi-Fi
Field reference
Windows & macOS · v0.4

1 How it works

One PC runs as the Host (Server) and holds the entire clinic database. Every other PC runs as a Cabin (Client) and works off the host over your network — cabins keep no data of their own. Data never leaves the clinic; there is no cloud in the middle.

🖥️ Host SERVER
The main PC (usually reception). Holds all data. Listens on port 4321.
→
🌐 Your router / switch
Network cables or Wi-Fi connect everyone to the same router. No internet needed.
→
💻 Cabins CLIENT
Doctor rooms, pharmacy, billing. Open the same live data as the host.
Before you start: put every PC on the same router/switch (avoid “Guest” Wi-Fi — it isolates devices), connect the host by network cable if you can, and keep the host awake (disable sleep). One host, any number of cabins.

2 Choose how the computers connect

The computers talk to each other over the clinic’s own network — nothing goes over the internet. Join them by network cable (best), by Wi-Fi, or — with only two computers — by one cable between them. They need not all connect the same way: the main computer on a cable and the others on Wi-Fi works well, as long as everyone is on the same router.

🔌 Network cable to the router or a switch
Recommended
  • The most reliable — it does not drop out or slow down.
  • Best for the main computer, which everyone else depends on.
  • Any number of computers: add a switch when the router runs out of sockets.
  • One cable from each computer to the router or switch.
  • Each computer needs a network (LAN) socket — a laptop without one needs a USB-to-LAN adapter.
📶 Wi-Fi
No wires
  • No cables to run — easy for laptops and far rooms.
  • Nothing to buy if the clinic already has a Wi-Fi router.
  • Can drop out or slow down when the signal is weak.
  • Keep the main computer on a cable if you can; use Wi-Fi for the others.
  • Every computer must join the same clinic Wi-Fi — not a “Guest” network.
↔️ One cable straight between two computers
Only two computers
  • No router or switch needed.
  • Private and fast — nothing else shares the cable.
  • Exactly two computers. A third one later needs a router or switch.
  • Both need a network (LAN) socket.
  • With no router, each computer needs a fixed address — the steps show exactly what to type.
One cable between two computers: give each a fixed address — main computer 192.168.77.1, other computer 192.168.77.2, subnet mask 255.255.255.0, and leave Default gateway and DNS empty.

3 Windows settings — on every computer

Almost every “the other computer can’t find the main one” is a Windows setting, not a CureDesk fault. Do these once, on each computer.

SettingWhyHow — Windows 11How — Windows 10
Join the same Wi-Fi on every computer
Needed · every computer · Wi-Fi		 Computers can only see each other on the same network. A “Guest” Wi-Fi usually keeps computers apart on purpose, so do not use it.
  1. Click the Wi-Fi symbol at the bottom-right of the screen.
  2. Choose the clinic’s Wi-Fi — the same name on every computer.
  3. Tick “Connect automatically”, then click Connect.
  4. Two or more bars of signal at least. If the main computer is far from the router, put it on a cable instead.
Same on Windows 11 and Windows 10.
Set the network to “Private”
Needed · every computer · Cable, Wi-Fi		 Windows marks a new network “Public” and then refuses connections from other computers. “Private” tells Windows this is your own clinic network.
  1. Open Settings → Network & internet.
  2. Cable: click Ethernet. Wi-Fi: click Wi-Fi, then the properties of the network you are on.
  3. Under “Network profile type” choose “Private network”.
  1. Open Settings → Network & Internet → Status.
  2. Under your connection (Ethernet or your Wi-Fi name) click Properties.
  3. Under “Network profile” choose “Private”.
Allow CureDesk through the Windows Firewall
Needed · every computer · Cable, Wi-Fi, Direct cable		 The Windows Firewall stops other computers from reaching CureDesk unless you allow it. Windows asks once, the first time CureDesk starts — a click on Cancel is the most common reason the computers cannot find each other.
  1. When Windows asks “Allow CureDesk HMS to communicate on these networks?”, tick “Private networks” and click “Allow access”.
  2. For a cable straight between two computers, also tick “Public networks” — Windows calls that cable a public network.
  3. Missed the question, or clicked Cancel? Open Windows Security → Firewall & network protection → Allow an app through firewall → Change settings → find “CureDesk HMS” and tick Private (and Public for a direct cable). Or use the two commands below: right-click the Start button → “Terminal (Admin)” or “Windows PowerShell (Admin)”, paste them, press Enter.
Allow CureDesk by hand (paste in PowerShell run as Administrator)
netsh advfirewall firewall add rule name="CureDesk HMS server" dir=in action=allow protocol=TCP localport=4321 profile=private,domain
netsh advfirewall firewall add rule name="CureDesk HMS finder" dir=in action=allow protocol=UDP localport=4322 profile=private,domain
For a cable straight between two computers use profile=any instead of profile=private,domain.
Same on Windows 11 and Windows 10.
Never let the main computer sleep
Needed · main computer only · Cable, Wi-Fi, Direct cable		 If the main computer goes to sleep, every other computer loses the clinic’s data at once and it looks like the network broke. The screen may still switch off — only “sleep” must be Never.
  1. Open Settings → System → Power & battery.
  2. Open “Screen and sleep”.
  3. Set “When plugged in, put my device to sleep after” to Never.
  1. Open Settings → System → Power & sleep.
  2. Under Sleep, set “When plugged in, PC goes to sleep after” to Never.
Stop Windows switching off the network card
Recommended · main computer only · Cable, Wi-Fi, Direct cable		 To save power Windows can switch the network card off for a moment, and then the main computer looks gone to the others.
  1. Right-click the Start button → Device Manager.
  2. Open “Network adapters” and double-click the one you use (a cable: “Ethernet”, “GbE” or “Family Controller”; Wi-Fi: “Wireless” or “Wi-Fi”).
  3. On the Power Management tab, untick “Allow the computer to turn off this device to save power”, then OK.
Same on Windows 11 and Windows 10.
Give the main computer a fixed address
Recommended · main computer only · Cable, Wi-Fi		 The other computers find the main one by its address. A router can hand out a different one after it restarts, and then the others lose it. A fixed address never changes.
  1. Best way — in the router: open its settings page (usually 192.168.0.1 or 192.168.1.1; the address and password are on the sticker under the router) and look for “DHCP reservation”, “Address reservation” or “Static lease”. Reserve an address for the main computer.
  2. Or in Windows: press the Windows key and R together, type “ncpa.cpl” and press Enter.
  3. Right-click your connection (“Ethernet” for a cable, “Wi-Fi” for Wi-Fi) → Properties.
  4. Double-click “Internet Protocol Version 4 (TCP/IPv4)”.
  5. Choose “Use the following IP address”. IP address: the same first three numbers as the router with a last number nobody else uses (for a router at 192.168.1.1, use 192.168.1.200). Subnet mask: 255.255.255.0. Default gateway and DNS server: the router’s address. Click OK.
Same on Windows 11 and Windows 10.
Give each computer its fixed address
Needed · every computer · Direct cable		 With one cable and no router nobody hands out addresses, so you give each computer one. Without it Windows waits a minute or more and then picks a number CureDesk cannot use.
  1. Press the Windows key and R together, type “ncpa.cpl” and press Enter.
  2. Right-click “Ethernet” (the one with the cable) → Properties.
  3. Double-click “Internet Protocol Version 4 (TCP/IPv4)”.
  4. Choose “Use the following IP address”. On the main computer type 192.168.77.1; on the other computer type 192.168.77.2. Subnet mask 255.255.255.0 on both.
  5. Leave “Default gateway” and “DNS server” EMPTY on both. Click OK.
Same on Windows 11 and Windows 10.
Keep the date and time right on every computer
Recommended · every computer · Cable, Wi-Fi, Direct cable		 Every bill and visit is stamped with the computer’s clock. A computer with the wrong time puts its entries at the wrong time on all the others.
  1. Open Settings → Time & language → Date & time.
  2. Turn on “Set time automatically” and “Set time zone automatically” (or choose India Standard Time).
  1. Open Settings → Time & Language → Date & time.
  2. Turn on “Set time automatically” and “Set time zone automatically” (or choose India Standard Time).
If you use another antivirus, allow CureDesk in it
Recommended · every computer · Cable, Wi-Fi, Direct cable		 Some antivirus programs (Quick Heal, K7, Kaspersky, Norton, McAfee …) have their own firewall that blocks other computers even when the Windows settings are right.
  1. Open the antivirus and find its Firewall (or Network protection) settings.
  2. Add “CureDesk HMS” to the allowed (trusted) programs, and mark this network as “Home” or “Trusted”.
Same on Windows 11 and Windows 10.
Then check it: in CureDesk open Settings → Computers & staff → Connect the computers and press Check this computer — it looks at the cable or Wi-Fi, the Windows network type and the sleep setting, and tells you what to fix.

4 What to buy

  • Network (LAN) cable, Cat6 — One for each computer, from the computer to the router or switch (for a direct cable: one cable between the two). Buy it ready-made — no crimping — and measure the route plus a metre or two spare. Any Cat5e or Cat6 cable works; no special “crossover” cable is needed. Search on Amazon.in
  • Network switch, 8-port Gigabit — Only if you have more computers than the router has LAN sockets (most routers have four). One cable goes from the router to the switch, and the computers plug into the switch. Search on Amazon.in
  • Wi-Fi router, dual-band (only if you need it) — The box your internet comes from. Any router will do for CureDesk — a better one just gives a steadier signal. Keep it in the middle of the clinic, not in a cupboard. Search on Amazon.in
  • UPS for the main computer (only if you need it) — A short power cut would switch off the main computer — and with it every other computer. A small UPS (also for the router and switch) gives a few minutes to carry on or shut down properly. Search on Amazon.in
  • USB-to-LAN adapter, Gigabit (only if you need it) — Only for a laptop or small computer with no network (LAN) socket. It plugs into a USB port and gives it one. Search on Amazon.in
  • USB Wi-Fi adapter (only if you need it) — Only for a desktop computer with no Wi-Fi of its own. Most laptops do not need one. Search on Amazon.in
These are plain Amazon.in searches — choose whatever make, length and price suits you, from any seller.

5 Set it up

🖥️ On the HOST PC SERVER
The PC that keeps the data — set this up first.
  1. Open Settings → Computers & staff → Connecting the Computers → Network Mode, choose Server, and Save. (First start? The Setup guide does this when you press “This is the main computer”.)
  2. When Windows/macOS asks, click Allow access so the port isn’t blocked by the firewall.
  3. Confirm the green banner: “✓ other PCs can reach this host at http://…:4321”. If it’s amber, fix the firewall / pick the wired adapter, then Re-check.
  4. Note the join code — 5 letters and numbers, capital and small letters are different (valid 10 minutes; press New code for another). Read out the code and the host address shown next to it.
💻 On each CABIN CLIENT
Repeat on every doctor / pharmacy / billing PC.
  1. Make sure it’s on the same network as the host.
  2. Open Settings → Computers & staff → Connecting the Computers → Network Mode and choose Client (or, on a fresh install, choose “This computer joins a clinic that is already set up” in the Setup guide).
  3. Pick the host under “Servers found on your network”, or type the 5-character join code from the host.
  4. It connects and reloads. The sidebar shows a connected pill — you’re now on the shared data.
✓ That’s it. Book a patient on a cabin — it appears on the host and every other cabin instantly. To take a PC back to standalone, set its Network Mode to Local.

6 When something’s wrong — recovery

SymptomMost likely causeWhat to do
Cabin: “server not reachable” Host off / not in Server mode / firewall blocking Check the host is running and set to Server; click Allow access on the firewall prompt. Re-check the host’s green banner.
Host banner is amber Firewall block, or wrong network adapter pinned Allow CureDesk through the firewall; under Troubleshoot pin the wired/Wi-Fi adapter the clinic uses; press Re-check.
Worked yesterday, dead today Host’s IP changed (router handed out a new one) Cabins now find the host again automatically. If one doesn’t, re-pair with a fresh join code. Prevent it for good → Golden Rule #1.
Cabin screen frozen Host went to sleep / lost power The app now times out to a clear error instead of hanging. Wake the host, or switch the cabin to Local to keep working, then back to Client.
Some PCs can’t see the host Different networks — Guest Wi-Fi, or one wired + one Wi-Fi kept apart Put everyone on the same router/switch. Avoid “Guest” networks and AP-isolation. Wired for the host is most reliable.
Always available: Settings → Computers & staff → Check this computer and Troubleshoot runs a step-by-step check (adapter → same network → port open → server answering → token accepted) and tells you, in plain words, exactly which step failed and how to fix it.

7 Golden rules (do these once)

📌
1 · Give the host a fixed IP
Add a DHCP reservation for the host on your router (or set a static IP). This stops the address ever changing — the single biggest cause of “it stopped working”.
☁️
2 · Back up the host
Only the host holds data. Turn on cloud backup: Settings → Backup → “Back up to my Google Drive”. Cabins need no backup.
🔌
3 · Keep the host awake & wired
Disable sleep on the host and connect it by cable. If the host is off, the whole clinic is off.
🔒
4 · Same clinic, same code
Cabins only join a host whose access code they were paired with — they’ll never latch onto a neighbouring clinic’s PC by mistake.
